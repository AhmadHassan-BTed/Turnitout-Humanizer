# Privacy Policy — Turnitout

**Effective Date:** August 4, 2026  
**Last Updated:** November 25, 2026

At **Turnitout** ("we", "our", or "us"), we are committed to protecting your privacy. This Privacy Policy explains how our Android application, website, and humanization platform handle your data.

---

## 1. Information We Collect & Process

### A. Manuscript & Document Content
- **Zero Permanent Storage**: All text, code comments, documents (`.docx`, `.tex`, `.txt`, `.md`, `.zip`), and citations submitted to Turnitout are processed **strictly in-memory** during your active session.
- We **do not store, log, sell, or index** your submitted manuscripts, papers, file names, or generated outputs on any database or external server.

### B. Optional Authentication & Session Data
- **Optional GitHub Verification**: When GitHub verification is enabled, we query GitHub's public REST API solely to check repository stargazer and follower status. No private GitHub data or emails are requested.
- **Session Cookies**: Short-lived browser cookies (`turnitout_unlocked`, `turnitout_github_username`) may be kept locally solely to maintain session continuity across reloads. We do not use advertising or tracking cookies.

### C. Aggregate Operational Language Counts
- **Language Detection**: Turnitout detects the language of your text in memory so text in an unsupported language is returned unchanged instead of altered.
- **Counts Only**: Each server keeps a daily tally of how many documents it processed per language code (for example, *English: 120, French: 3*) and operational status codes. These logs never contain your text, phrases, or file names.
- **Background Testing & Experimental Opt-In**: Experimental language opt-ins last only for your session or single request and are not permanently stored.

---

## 2. Advertising & Third-Party Services

- **No Advertising SDKs**: Turnitout contains zero third-party ad networks.
- **No Third-Party Analytics**: We do not share, sell, or monetize any user data with data brokers or analytics providers.

---

## 3. Data Retention & Deletion

- Your manuscript content is discarded immediately in memory upon completion of each request.
- Anonymous daily aggregate language counts (Section 1C) expire automatically after 30 days.
- Clearing browser cache or Android app storage removes all local session state immediately.
