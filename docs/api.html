Core Endpoints

POST /v1/citations

Contextual academic citation inserter & BibTeX generator. Inserts citations at claim boundaries without paraphrasing the original text, returning matching BibTeX references with self-executing AI auto-fill instruction headers.

{ "text": "Machine learning architectures provide notable improvements in analyzing genomic sequences and predicting protein tertiary structures.", "citation_count": 2, "citation_format": "IEEE [1]", "discipline": "biology" }

Query current word quota, consumed balance, remaining words, and active tier configuration.
