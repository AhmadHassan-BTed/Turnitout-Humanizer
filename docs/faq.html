Frequently Asked Questions

STUDENT KNOWLEDGE BASE

1. Is TURNITOUT really free with no word caps?

Yes. Unlike commercial services that lure you with a 125-word free trial before asking for $20/month, TURNITOUT has no word count caps, no tiers, and no trial limits. It was built as a student's gift to the community.

2. Does it guarantee a 0% AI score on Turnitin?

Turnitin and other detectors update their proprietary classifiers continuously. No legitimate tool can guarantee a perpetual 0% score across every single algorithm. However, TURNITOUT systematically dismantles the predictable n-gram patterns, low-entropy vocabulary, and discourse markers that trigger detector alerts.

3. Why do you ask for GitHub stars instead of charging money?

Charging students money for simple text transformation is predatory. Open-source development runs on visibility and community recognition. By starring our repositories and following our profiles, you help the project grow, reach other students, and remain free for future cohorts.

4. Can I use TURNITOUT for source code and programming assignments?

Yes! TURNITOUT includes a dedicated Code Comment Humanizer supporting Python, C/C++, Java, JavaScript, Go, Rust, Shell, and SQL. It only modifies natural language comments and docstrings, leaving code statements, variable names, functions, and logic completely untouched and 100% executable.
