Privacy Policy — Turnitout

Effective Date: August 4, 2026 • Last Updated: November 25, 2026

At Turnitout ("we", "our", or "us"), we are committed to protecting your privacy. This Privacy Policy explains how the Turnitout Android application, website, and web platform handle your data.

1. Information We Collect & Process

A. Manuscript & Document Content

  • Zero Permanent Storage: All text, code comments, documents (.docx, .tex, .txt, .md, .zip), and citations submitted to Turnitout are processed strictly in-memory during your active session.
  • No Text Logging: We do not store, retain, sell, or index your submitted manuscripts, prompts, file names, or generated outputs in any database.

B. Optional Authentication & Session Cookies

  • Optional GitHub Verification: Where optional GitHub verification is enabled, public GitHub API checks verify repository stargazer or follower status. No private GitHub repositories, tokens, or emails are requested.
  • Session State: Short-lived browser cookies (turnitout_unlocked, turnitout_github_username) may be stored locally on your device to preserve active session convenience.

C. Aggregate Operational Language Counts

  • Turnitout runs in-memory language detection solely so unsupported scripts are returned unchanged without corruption.
  • Anonymous aggregate daily counts by language code and status codes are kept for up to 30 days to guide multilingual support. These logs never contain user text, phrases, or file names.

2. Advertising & Third-Party Trackers

Turnitout contains no third-party advertising SDKs and does not sell or share personal data with data brokers or ad networks.

3. Data Retention & Deletion

  • Your document text is discarded immediately in memory once processing finishes.
  • Clearing browser cache or Android app storage immediately erases all local session state.
  • Anonymous aggregate language counts expire automatically after 30 days.
