1. System Architecture & Deterministic Philosophy

Conventional commercial AI rewriters (QuillBot, Undetectable AI, StealthGPT) route text through third-party Large Language Models (LLMs). This introduces three fatal flaws for academic and professional documents:

  1. Factual Hallucinations: Generative models randomly invent statistics, dates, citation numbers, and theorem claims.
  2. Secondary AI Fingerprints: LLM output inherently exhibits low mathematical perplexity and uniform sentence length, frequently triggering detectors like Turnitin AI and CopyLeaks anew.
  3. Formatting Destruction: Plaintext LLM wrappers obliterate complex Word XML styles, LaTeX math environments, tables, equations, and code indentation.

The Turnitout Paradigm (Black-Box Guarantee): Turnitout uses zero generative AI. It functions as a deterministic linguistic transformation pipeline. Input text passes through structured syntactic parsing, contextual synonym realignment, n-gram chain disruption, and discourse connective rotation. All facts, equations, numerical values, and document layouts remain mathematically sealed.

2. Core Module: Plagiarism & AI Humanizer

The primary humanization workspace provides dual operating modes: direct prose entry and multi-format document ingestion.

2.1 In-Place Document Parsing & Layout Preservation
Word (.docx) LaTeX (.tex) Markdown (.md) Plain Text (.txt) Batch ZIP Archives

Unlike converters that flatten documents to plain text, Turnitout operates directly on document Abstract Syntax Trees and XML run streams:

  • Microsoft Word (.docx): Traverses w:p (paragraphs) and modifies only inner w:t text runs. Formatting runs (bold, italic, font face, text highlighting, paragraph alignment, headers, footers, tables, and drawing objects) remain untouched.
  • LaTeX (.tex): Isolates natural language body prose while mathematically protecting math modes ($...$, \[...\]), environments (\begin{equation}, align, matrix), citation anchors (\cite{...}), and document preambles.
  • Batch ZIP Processing: Upload archives containing multiple documents. Turnitout processes each file in-memory and delivers a bundled ZIP export (Turnitout_Humanized_Docs_<TIMESTAMP>.zip) preserving relative path hierarchies.
2.2 Watermark, Hidden Unicode & Metadata Scrubbing
Anti-Tracking EU AI Act Compliance Automatic

Turnitout automatically scrubs modern tracking footprints embedded by generative AI providers to comply with watermarking regulations:

Tracking Mechanism How Providers Inject It Turnitout Functional Outcome
Zero-Width Unicode Spaces Hidden characters (U+200B, U+200C, U+200D, U+2060) inserted between words as steganographic watermarks. Deep regex character scrubbing detects and purges all invisible zero-width code points without altering visible spacing.
C2PA Manifest Metadata Provenance manifests embedded in Office and PDF document packages indicating AI generation origins. Document packaging streams are sanitized upon export, wiping internal generation markers from file history.
LLM Cliché Signatures High-frequency AI marker phrases (e.g. "delve into", "pivotal role", "testament to", "tapestry") and em-dashes (—). Targeted catalog disruption identifies cliché n-grams and substitutes natural, varied academic phrasing.
2.3 Advanced Transformation Controls (The 14 Knobs)
Fine-Tuning Interactive Controls

Inside the expandable Advanced Transformation Settings & Protected Terms panel, users can customize individual syntactic passes:

Control Knob Functional Behavior (What Happens) Cadence / Perplexity Effect
1. Synonym Swapping Substitutes predictable lexical tokens with contextually aligned synonyms. Governed by the Alignment Probability Slider (0.50 to 1.00). Disrupts low-entropy n-gram chains while maintaining strict semantic equivalence.
2. Phrase Rewriting Replaces multi-word idiomatic patterns and repetitive transitional phrases with varied natural equivalents. Breaks contiguous 3-gram and 4-gram frequency peaks evaluated by AI detectors.
3. Determiner Swapping Contextually alternates demonstratives and articles (e.g., "the" ↔ "this", "these" ↔ "such"). Prevents rigid determiner distribution common in machine-generated summaries.
4. Voice Transformations Converts eligible passive constructions to active voice and vice-versa based on academic discourse conventions. Elevates stylistic burstiness and varies sentence grammatical subject agency.
5. Sentence Fusion Fuses adjacent short, choppy sentences using coordinate and subordinate conjunctions. Increases syntactic complexity and smooths reading rhythm.
6. Transition Injection Injects varied academic discourse markers (e.g., "Furthermore", "In contrast", "Consequently"). Elevates structural coherence (adds word count; disable for strict limits).
7. Clause & Word Reorder Permutes dependent clauses, introductory adverbials, and prepositional phrases to natural alternative positions. Shifts sentence opening rhythms with zero change to total word count.
8. Nominalization / Verbalization Alternates between action verbs and abstract nominal forms (e.g., "analyze" ↔ "conduct an analysis of"). Calibrates formal academic density without introducing external vocabulary.
9. Appositive Insertion Inserts clarifying parentheticals, acronym definitions, and appositive noun phrases. Mimics human explanatory prose (adds word count; disable for strict limits).
10. Discourse Rotation Rotates paragraph-level rhetorical flow and macro-connectives according to discourse tree conventions. Eliminates predictable paragraph opener templates across long manuscripts.
11. Contractions Swapping Expands contracted auxiliaries (e.g., "don't" ➔ "do not") for formal papers, or contracts for casual tones. Alters token length and tone consistency.
12. N-Gram Chain Breaking Performs a final audit of surviving 5-gram token chains against common AI sequences, applying micro-substitutions. Shatters hash fingerprints tested by Turnitin and Winnowing detectors.
13. Conceptual Bridging Injects thematic transition connectors between adjacent conceptual paragraphs. Enhances multi-paragraph narrative cohesion (adds word count).
14. Information Reordering Restructures sentences to shift information focus (given vs. new information principle). Optimizes reader focus and rhetorical cadence with zero word expansion.

3. Core Module: Code Comment & Docstring Humanizer

Designed for computer science students, software engineers, and researchers submitting programming assignments.

3.1 AST String-Aware Comment Isolation (100% Executable Safety)

The single most dangerous failure of generic rewriters on source code is altering syntax, variable names, or string literals. Turnitout features a string-aware tokenizer that tracks quote contexts (single quotes, double quotes, escape sequences) to isolate only natural language comment tokens:

# ONLY comments like this are rewritten def calculate_loss(y_true, y_pred): "String literals 'like this' are strictly untouched" return np.mean((y_true - y_pred) ** 2)

Supported languages: Python, R, JavaScript, TypeScript, Java, C, C++, C#, Go, Rust, PHP, Swift, Kotlin, Bash/Shell, SQL, and HTML/CSS/XML.

3.2 Developer Skill Personas

Match comment vocabulary to your intended developer seniority level:

  • Beginner Developer: Uses simple, everyday conversational terminology (e.g., "checks if list is empty", "loops through numbers").
  • Intermediate Developer: Standard industry working English (e.g., "validates container boundary", "iterates across dataset").
  • Senior Architect / Expert: High-density technical jargon (e.g., "evaluates invariant constraint", "executes sequential traversal").
3.3 Docstring Conversion

Generative AI tools (ChatGPT, GitHub Copilot) frequently generate verbose triple-quoted docstrings (""" ... """). Enabling Convert AI Docstrings → Human '#' Comments automatically refactors multi-line docstring blocks into natural, concise line-by-line developer comments.

8. Power-User FAQ & Quick Troubleshooting

Q: My transformed document grew in word count. How do I lock it to 0 added words?

Open Advanced Transformation Settings & Protected Terms. Keep Synonym Swapping enabled (slider at 0.85 – 0.90), and turn OFF Transition Injection, Appositive Insertion, and Conceptual Bridging. The engine will perform strict 1:1 substitutions with 0 net words added. Read the dedicated Word Limit Guide for full details.

Q: Does Turnitout modify formulas, citations, or figure captions in LaTeX?

No. Turnitout's LaTeX parser strictly protects all math environments ($...$, \[...\], equation, align), macros (\cite{...}, \ref{...}), tabular columns, and preambles. Only natural prose paragraphs receive linguistic realignment.
